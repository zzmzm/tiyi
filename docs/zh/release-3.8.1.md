# 太一 Tiyi v3.8.1

发布日期：2026-11-12。

## 主要变化

- 可选 AI 助手支持日志、IP、告警与配置调查；连续对话、审核和修改建议、真实客户端 IP 诊断与报告使用权限范围内的证据及内置运维知识。
- 定时生成报告、跟进调查与告警交接摘要。明确的 IP 目标、事件数量条件和有效期可授权有界自动动作，模型文字不能代替授权。AI 默认关闭，不参与请求处理。
- 自定义规则支持分组 AND/OR 条件、请求与响应字段、结构化正文及明确的检查依赖；支持预览、测试、历史与经审核版本恢复。节点不具备所需能力时拒绝发布。
- 从安全事件起草精确规则例外，预览作用范围并批量审核 CRS 调整；选择仅跳过 CRS 的例外时，太一自定义规则与 IP 控制仍生效。
- 访问、安全与错误日志提供紧凑筛选、可编辑时间范围、日历选择和按已应用查询导出；保留期限明确区分历史不可用与零事件，过期分区不再引起查询错误。
- 修复控制台页面切换与弹窗生命周期，AI 上下文归属当前页面；保留明确的保存、节点应用与请求证据结果。公开 CLI/API 参考与发行版同步。

## 从 v3.8.0 升级

先备份完整安装与匹配的二进制。v3.8.1 保留 v3.8.0 的状态边界（schema 143），启动时对 v3.8.0 状态执行新增迁移。发布依赖新节点能力的规则前，将 Controller 与远端 Agent 升级至 v3.8.1。本次更新不要清除 v3.8.0 状态。

按[备份与签名更新指南](https://www.tiyisec.com/zh/docs/upgrade-migration.html)操作。更新器校验后替换二进制；有计划地重启，并验证健康、节点应用及正常与拦截请求。迁移后回滚应使用升级前的完整备份和匹配二进制，不要让旧二进制打开已迁移状态。

v3.7.2 及更早状态仍不兼容，跨越该旧边界时按文档重建状态并重新注册远端 Agent。AI 提供商与外部集成取决于所配置服务，本次发行不代表所有提供商或物理集群均已完成验收。

## 签名下载

Linux amd64 与 arm64 压缩包包含可执行文件、签名、发行元数据、本文及许可声明。使用公开的 release-key.pub 校验 SHA256SUMS 与 SHA256SUMS.sig。
